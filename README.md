# ShortOps (가칭)

유튜브 쇼츠 제작 운영자를 위한 SaaS 설계 문서 저장소입니다.

## 포함 문서
- `docs/shortops-mvp-prd.md`: MVP 제품 요구사항(PRD), 정책 가이드, 아키텍처, 데이터 모델, API/룰 엔진 정의
- `presets/community-info-factory.json`: 커뮤니티/정보형 양산 템플릿 프리셋
- `presets/recap-explainer.json`: 리캡/해설형 템플릿 프리셋

## 목표
- 벤치마킹 분해 규칙을 템플릿화
- 소재 파이프라인(수집→우선순위→대본 연결) 구축
- 대본 생성 + 체크리스트 진단 자동화
- TTS/SRT/로컬라이징 + SOP 자동화로 분업 운영 지원
